# 요양보호사 근무일정표 프로그램 기획안 Nov 4, 2026 · @IN HWAN, KIM ## 1. 개요 요양보호사(간병인력) 근무표를 **규칙 기반으로 자동 생성하고, 수정·교환·법정 기준 점검까지 한 화면에서 처리**하는 웹 프로그램을 만든다. 1단계는 모든 요양병원에 공통인 기능만 담고, 병원별 차이는 코드 수정 없이 "설정"으로 흡수한다. **현장의 문제 (30년 현장 기준)** - 근무표를 엑셀·수기로 짜느라 수간호사·팀장이 매달 1\~2일을 쓴다. - 야간 연속, 휴무 쏠림, 연속 근무일 초과가 사람 눈으로는 잘 안 걸러진다. - 갑작스러운 결근·근무 교환이 카톡·구두로 처리돼 기록이 남지 않는다. - 병동별 최소 인원이 비는 시간대가 사후에야 드러난다. - 급여 정산(야간·휴일 수당)과 근무표가 따로 놀아 매달 대조 작업이 생긴다. **목표** | 목표 | 측정 기준 | | --- | --- | | 월 근무표 작성 시간 단축 | 1\~2일 → 2시간 이내 | | 인원 공백 사전 차단 | 확정 근무표의 최소 인원 미달 0건 | | 공정한 배분 | 직원 간 야간·주말 근무 횟수 편차 ±1회 이내 | | 변경 이력 투명화 | 교환·대체 근무 100% 시스템 기록 | **범위** - 포함(1단계): 직원·병동·근무유형 관리, 월 근무표 자동 생성과 수동 편집, 휴무 신청, 근무 교환, 규칙 위반 점검, 근무 통계, 출력·엑셀 내보내기. - 제외(이후 단계): 급여 계산, 출퇴근 기록기 연동, 간호사·조무사 통합 편성, 입원환자 수 연동 인력 산정. ## 2. 사용자와 권한 권한은 4단계로 나누고, 병동 단위로 볼 수 있는 범위를 제한한다. | 역할 | 누구 | 주요 권한 | | --- | --- | --- | | 시스템 관리자 | 행정원장, 전산 담당 | 병원 설정, 근무코드·규칙 편집, 사용자·권한 관리 | | 근무표 책임자 | 간호부장, 수간호사, 요양보호팀장 | 담당 병동 근무표 생성·편집·확정, 휴무·교환 승인 | | 직원 | 요양보호사(간병인력) | 본인 근무표 조회, 희망 휴무·연차 신청, 교환 요청 | | 열람자 | 병원장, 이사장, 노무 담당 | 전체 근무표·통계 조회만 | -
